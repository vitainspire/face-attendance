      Photo Storage

      Student photos are stored in your own private storage bucket, not shared with any other school. Follow these steps once to set it up (about 5 minutes) — you won't need to do this again unless you want to change buckets later.

      Step 1 — Create a storage bucket

      1. Go to aws.amazon.com/s3 and sign in (or create a free AWS account if you don't have one).

      2. Search for "S3" at the top and open it.

      3. Click Create bucket. Give it any unique name (e.g. yourschoolname-photos). Leave all other settings as the default. Click Create bucket at the bottom.

      Step 2 — Create an access key for this bucket

      1. Search for "IAM" at the top and open it.

      2. Click Users (left menu) → Create user. Give it any name (e.g. attendance-app) → click through to Create user.

      3. Click on the user you just created → the Permissions tab → Add permissions → Attach policies directly → search for and check AmazonS3FullAccess → Add permissions.

      4. Still on that user's page, click the Security credentials tab → scroll to Access keys → Create access key → choose "Application running outside AWS" → Next → Create access key.

      5. Copy the Access key and Secret access key shown — this is the only time the secret key is ever shown. Paste both below.

      Recognition Settings

      Controls how confident the camera needs to be before a student is automatically checked as present on the teacher's attendance checklist. This does NOT make recognition itself more or less accurate — it only changes how much the teacher is asked to double-check.

      Lower (e.g. 70%) — more students get auto-checked present, but more risk of a wrong auto-check slipping through unnoticed.
      Higher (e.g. 95%) — fewer wrong auto-checks, but more students will need the teacher to manually confirm or check them.

      Attendance "today" and upcoming events use this to mean YOUR school's calendar day, not necessarily the UTC one. Leave at 0 (or blank) if unsure — India Standard Time is 330 (UTC+5:30).
